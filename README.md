# الستور ⚡ برنامج محل الأدوات المنزلية والأجهزة الكهربائية

**النسخة 1.0.0 — نسخة تجربة أولى (pilot).** معمول بالمصنع ([Apps-Factory](https://github.com/coolman1984/Apps-Factory)).
بيشتغل على جهاز المحل نفسه **من غير نت**، والموبايل بيفتحه من على واي فاي المحل.

## بيعمل إيه؟ 🧭
| الحاجة | ببساطة |
|---|---|
| 🛒 البيع | بالباركود أو بالاسم، من غير ماوس (F2 للبحث، Enter للإضافة، F4 للدفع، F8 لتعليق الفاتورة) |
| 💳 الدفع | كاش (وبيحسب الباقي)، وفيزا، ومحفظة، وإنستاباي، وشركات التقسيط، وآجل على الحساب، وتقسيط المحل بمقدّم وضامن، وأكتر من طريقة في نفس الفاتورة |
| 🛡️ الضمان | سيريال لكل جهاز، وكشف ضمان بالسيريال: اتباع إمتى، ولمين، وفاضل في الضمان قد إيه |
| ↩️ المرتجع | مربوط بالفاتورة الأصلية، بموافقة المدير، والبضاعة السليمة بترجع للرف والتالفة لمكان الصيانة |
| 📦 المخزن | المعرض والمخزن والرفوف، ونقل بالسيريال، وجرد رف رف |
| 🏷️ الأسعار | سعر بيع، وسعر فني، وأقل سعر. وتقدر ترفع أسعار ماركة كاملة بنسبة من يوم تختاره، مع معاينة قبل التطبيق |
| 💰 الخزنة | وردية لكل كاشير بالفكة، ومصاريف، وتوريد للخزنة الرئيسية، وقفل بالعدّ يطلّع الزيادة أو العجز |
| 👁️ عين صاحب المحل | الخصومات الكبيرة، والبيع بأقل من التكلفة، والمرتجعات، وعجز الدرج، والمصاريف الكبيرة، والبيع بعد مواعيد المحل |
| 📊 التقارير | المبيعات، والمكسب، وطرق الدفع، والأقسام، والماركات، والبيّاعين، وقيمة المخزون، والبضاعة الواقفة، ومبيعات السنة (عشان الضريبة المبسطة) |
| 🔐 الأمان | كل واحد بيدخل باسمه بصلاحياته، والفلوس مبتتمسحش (بتتعكس بس بسبب)، ونسخ احتياطية لوحدها |

## التشغيل 🚀
```bash
python server/app.py              # المحل الحقيقي: أول مرة بيطلب اسم المحل وحساب صاحب المحل
python server/app.py --practice   # محل تدريب ببيانات وهمية (owner / practice-1234)
```
على ويندوز: `start.bat` (المحل) و`practice.bat` (التدريب). البيانات والنسخ في فولدر `shop-data` جنب البرنامج (أو `%ProgramData%\Al-Store` في النسخة المتسطّبة).

## كود التشغيل (نسخة تجربة أسبوعين) 🔑
1. البرنامج بيوريك **رقم الجهاز** في «الإعدادات» ← «الرخصة».
2. الشركة بتطلّع كود من **برنامج الأكواد** (Licence Studio في المصنع) مربوط برقم الجهاز ده ولمدة 14 يوم.
3. تلزق الكود والبرنامج يشتغل. بعد ما المدة تخلص، البيع والتعديل بيقفوا لحد كود جديد، **لكن البيانات عمرها ما بتتمسح ولا بتتقفل**: تقدر تفتحها وتطبعها وتصدّرها وتعمل نسخة احتياطية.

> المفتاح العام بتاع الشركة بيتحط في `licence_keys.txt` وقت تجهيز النسخة. المفتاح الخاص عمره ما بيدخل الريبو.
